# 에셋 가이드 (ASSETS)

이 문서는 디자이너가 무료 모델과 이미지를 게임에 넣을 때 따르는 절차입니다. 맵 이름 규칙은 [MAP_SPEC.md](MAP_SPEC.md), 설정 방법은 [SETUP.md](SETUP.md) 를 보세요.

## 1. Creator Store 에서 무료 모델 찾기

Creator Store 는 Roblox 사용자가 올린 모델 저장소입니다. Studio 안에서는 Toolbox 로 검색합니다.

1. Studio 메뉴에서 Toolbox 를 찾아 엽니다.
2. 검색창에 아래 검색어를 입력합니다.
3. 필터에서 무료(Free) 항목만 보도록 설정합니다.
4. 원하는 모델을 골라 Studio 에 삽입합니다.

### 검색어 목록

영어 검색어를 쓰세요. 한국어 검색은 결과가 매우 적습니다.

| 만들 것 | 검색어 |
| --- | --- |
| 로버 | moon rover |
| 착륙선 | lunar lander |
| 기지 모듈 | space habitat module |
| 패널 | solar panel |
| 바위 | moon rock |
| 크레이터 지형 | crater terrain |
| 우주인 | astronaut |

한국어 검색어로 찾으면 결과가 거의 없거나 관련 없는 모델이 나옵니다. 그래도 한국어로 찾고 싶다면 영어 검색어와 함께 씁니다.

## Sketchfab 무료 키트 가져오기 (Ultimate Space Kit)

팀이 비주얼 콘셉트로 확정한 에셋은 Quaternius 의 Ultimate Space Kit 입니다. 위의 Creator Store 검색 대신 이 키트를 Sketchfab 에서 받아 Studio 에 가져옵니다.

- 키트 페이지: https://sketchfab.com/3d-models/ultimate-space-kit-84c108ff2bcf4d4cbf2adff74a942822
- 구성: 로우폴리 모델 90종 이상 (돔, 로버, 모듈 컨테이너, 우주인, 바위, 행성)
- 라이선스: 페이지에는 CC Attribution(CC-BY)으로 표시되어 있고, 설명란에는 CC0이라고 적혀 있습니다. 두 표기가 다르므로 받기 전에 페이지의 라이선스 표시를 직접 확인하세요.
- 크레딧: 어느 쪽이든 게임 설명에 아래 한 줄을 넣습니다.

```text
Ultimate Space Kit by Quaternius, CC-BY
```

### 1. 다운로드

1. Sketchfab 에 로그인합니다.
2. 키트 페이지에서 Download 3D Model 을 누르고 glTF(권장) 또는 FBX 형식을 고릅니다.
3. 압축을 풀고 모델별 파일이 어떻게 나뉘어 있는지 확인합니다.
4. 키트 전체는 약 18만 삼각형입니다. 한 번에 모두 가져오지 말고, 아래 2번처럼 필요한 조각만 하나씩 가져옵니다.

### 2. Studio 3D Importer 로 가져오기

1. Studio 메뉴에서 Import 3D 를 찾으세요. Home 또는 Avatar 탭에 있을 수 있습니다.
2. 파일을 선택하고 가져옵니다.
3. 필요한 조각만 가져옵니다.
   - 로버 1개
   - 착륙선 1개
   - 거주 모듈 3종. A 거주, B 농장, C 연구실이 색이나 형태로 서로 구분되는 것을 고릅니다.
   - 태양광 패널 1개
   - 바위 2-3종
4. 가져올 때 아래 세 가지를 확인합니다.
   - 스케일: 로버가 캐릭터 키 5 스터드 기준으로 어울리는지 봅니다.
   - 삼각형 상한 경고: Studio 가 메시당 삼각형 상한 경고를 띄우면 그 메시지를 따릅니다. 정확한 상한 수치는 이 문서에 적지 않았습니다.
   - 재질과 텍스처: 가져온 뒤 색과 재질이 살아 있는지 확인합니다.

### 3. MAP_SPEC 이름에 맞춰 조립

가져온 조각은 [MAP_SPEC.md](MAP_SPEC.md) 의 이름과 구조에 맞춰 조립합니다.

- **로버**: 로버 모델 안에 VehicleSeat 를 넣고 이름을 `DriverSeat` 로 합니다. 로버 Model 의 PrimaryPart 를 지정합니다.
- **모듈 A, B, C**: BaseKit 안의 `ModulePads` 폴더 아래에 `PadA`, `PadB`, `PadC` 모델을 둡니다. 각 모델 안에 세 부품을 넣습니다.
  - `Pad` (Part): 건설을 시작하는 자리
  - `Ghost` (Model): 건설 중 보이는 반투명 복제본. 투명도는 0.7 입니다.
  - `Built` (Model): 완성 모델
  - `PadA` 에는 `OxygenZone` (Part) 도 넣습니다.
- **착륙선**: 착륙선 모델 안에 `SpawnPoint` (Part) 와 `OxygenZone` (Part) 를 넣습니다.
- **전체 묶음**: 모든 것을 `ServerStorage` 의 `BaseKit` 모델로 묶습니다. PrimaryPart 는 `Origin` 입니다.

완성되면 코드가 그레이박스 대신 이 키트를 그대로 사용합니다. 이름이 하나라도 다르면 맵이 제대로 뜨지 않습니다.

### 4. 스크립트 확인

키트 메시 안에는 스크립트가 없을 것으로 보입니다. 그래도 위 3-1 절과 같은 방법으로 Script, LocalScript, ModuleScript 가 있는지 한 번 확인합니다.

## 2. 라이선스 확인

모델을 쓰기 전에 아래 두 가지를 확인합니다.

- 만든 사람(Creator) 이름과 모델 설명을 봅니다.
- 모델 페이지의 라이선스와 사용 조건을 확인합니다. 조건이 불분명하면 쓰지 않습니다.

이 게임은 해커톤 출품작이므로, 상업적 재배포 조건이 있는 모델은 피하는 것이 안전합니다.

## 3. 반드시 할 안전 점검

무료 모델에는 숨은 스크립트가 들어 있는 경우가 많습니다. 모델을 Studio 에 넣은 뒤 **모든 스크립트를 먼저 지우고** 그다음에 맵에 배치하세요.

### 3-1. 스크립트 찾아서 지우기

1. 가져온 모델을 Explorer(탐색기)에서 선택합니다. Explorer 가 안 보이면 Studio 메뉴에서 찾으세요.
2. Explorer 위쪽의 검색 기능을 쓰거나, 모델 트리를 펼쳐서 확인합니다.
3. 검색어로 `Script` 를 입력하면 Script, LocalScript 가 함께 걸립니다.
4. 나온 항목을 전부 삭제합니다. ModuleScript 도 같은 방법으로 찾아서 확인하고, 용도를 모르면 삭제합니다.
5. 삭제한 뒤 모델을 한 번 더 선택해서 하위에 스크립트가 남지 않았는지 확인합니다.

스크립트를 지우면 모델이 움직이지 않을 수 있습니다. 게임 동작은 우리 프로젝트의 `src` 코드가 담당하므로, 무료 모델의 스크립트는 필요 없습니다.

### 3-2. 플러그인 설치 금지

요구 사항에 없는 플러그인은 설치하지 마세요. 플러그인은 Studio 전체에 권한을 가질 수 있습니다. 필요한 플러그인이 있으면 먼저 팀에 공유하고 승인받습니다. Rojo 플러그인은 `rojo plugin install` 로 설치하는 것이므로 예외입니다.

## 4. 모델을 MAP_SPEC 이름에 맞추기

무료 모델은 우리 맵 명세와 이름이 다릅니다. 가져온 뒤 이름과 클래스를 맞춥니다.

예를 들어 로버 모델을 가져왔다면 다음과 같이 바꿉니다.

1. 로버 모델 안에서 운전석 역할을 하는 시트를 찾습니다.
2. 시트의 클래스를 VehicleSeat 로 바꾸거나, 새 VehicleSeat 를 만들어 그 위치에 놓고 원래 시트를 지웁니다.
3. VehicleSeat 의 이름을 `DriverSeat` 로 바꿉니다.
4. 로버 Model 을 선택하고 PrimaryPart 를 로버 본체 Part 로 지정합니다.
5. [MAP_SPEC.md](MAP_SPEC.md) 의 `Rover` 항목과 맞는지 확인합니다.

다른 에셋도 같은 원리입니다. 패널은 `PanelTemplate`, 건물은 `Built` 와 `Ghost` 처럼 MAP_SPEC 에 적힌 이름에 맞춥니다.

## 5. 비주얼 톤 가이드

게임 분위기를 맞추기 위한 기준입니다.

- **키트 기준**: Ultimate Space Kit 의 밝은 컬러 로우폴리 톤을 기준으로 합니다. 지면은 회색 달 표면, 하늘은 어둡게 둡니다.
- **달 표면**: 어두운 회색 계열입니다. 밝은 흰색 땅은 쓰지 않습니다.
- **기지**: 흰색 건물에 주황색 포인트를 씁니다.
- **UI 색**: [CONTRACT.md](CONTRACT.md) 5절을 따릅니다. 배경은 어두운 남색 계열, 글씨는 흰색입니다. 강조색은 에너지 노랑, 물 하늘색, 식량 초록, 산소 주황입니다.
- **버튼 크기**: 모바일 터치도 고려해서 버튼은 최소 44px 로 만듭니다.

## 6. 이미지 업로드 (타이틀, 조종석)

타이틀 화면 그림과 조종석 정지 이미지는 PNG 파일을 Studio 에 올려서 씁니다. 지원 님이 만든 AI 이미지가 이 경우에 해당합니다.

1. Studio 메뉴에서 Asset Manager 를 찾아 엽니다.
2. 이미지 파일(PNG)을 업로드합니다.
3. 업로드가 끝나면 이미지의 ID 가 생깁니다. 이 ID 로 `rbxassetid://번호` 형식의 주소를 만듭니다.
4. Studio 에서 ImageLabel 을 만들고, 그 Image 속성에 주소를 넣습니다.
5. 검수가 끝나기 전에는 이미지가 안 보일 수 있습니다. 검수에는 시간이 걸릴 수 있으니, 먼저 임시 이미지로 화면을 만들어 두고 나중에 바꿉니다.

이미지 주소는 개발자에게 전달해서 UI 코드에 넣도록 합니다. 주소 번호는 디자이너가 직접 기록해서 팀 채널에 남깁니다.
