The Frontier - 적대적 리뷰 프롬프트 모음 (Codex 등 외부 에이전트용)

사용법
1. 리뷰 에이전트를 저장소 루트(/Users/jaden/Documents/해커톤/나사/the-frontier)에서 실행한다.
2. 프롬프트는 반드시 두 파일을 이어 붙여 전달한다.
   [01_공통_컨텍스트.txt 전체] + [역할 파일 하나 전체]
   공통 컨텍스트에는 게임 목적, 저장소 구조, 읽어야 할 문서, 검증 가능 범위, 출력 규칙이 들어 있다.
3. 역할은 독립적이다. 한 번에 하나씩 돌리고, 가능하면 서로 다른 세션에서 돌려 서로의 결론에 끌려가지 않게 한다.
4. 각 리뷰어는 결과를 docs/reviews/<역할번호>_<역할명>.md 로 쓰도록 지시되어 있다. 코드는 수정하지 않는다.
5. 다섯 보고서가 모이면 docs/reviews/ 를 통째로 우리 세션에 넘겨 우선순위를 합친다.

역할 파일
- 02_게임정책_리뷰어.txt      : 규칙, 밸런스, 교육 목적 달성, 악용과 지루한 구간
- 03_UI_UX_리뷰어.txt         : HUD, 프롬프트, 온보딩, 가독성, 모바일, 피드백 루프
- 04_로블록스_플랫폼_리뷰어.txt : 로블록스 기능을 충분히 쓰는지, 멀티플레이, 보안, 성능, 배포
- 05_몰입도_연출_리뷰어.txt    : 달 위에 있다는 느낌, 사운드, 효과, 카메라, 서사, 인트로
- 06_기술_보안_리뷰어.txt      : Luau 런타임 오류 가능성, Remote 검증, 재시작 정리, 테스트 공백

권장 순서: 02 -> 05 -> 03 -> 04 -> 06. 목적과 몰입을 먼저 보고, 그 결론을 UI와 플랫폼 활용으로 내려간다.

주의
- 리뷰어는 Roblox Studio를 실행할 수 없다. 코드, 문서, 테스트, 그리고 공통 컨텍스트의 플레이테스트 기록만으로 판단한다. 확신이 낮은 항목은 그렇게 표시하라고 지시되어 있다.
- 리뷰어가 코드를 고치려 하면 막는다. 우리는 보고서만 받는다.
