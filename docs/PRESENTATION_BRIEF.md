### 챌린지
- 이름: "Build a Junior Astronaut Mission Trainer"
- 대상: 7~12세 어린이. 형제자매, 부모, 교실에서도 함께 쓸 수 있는지 고려하라고 명시.
- 핵심 요구(챌린지 원문, Figma Page 1 "챌린지 내용"):
  - 실제 우주 임무의 제약을 게임으로 바꿔, 대가 없는 선택이 없게 할 것(트레이드오프)
  - 가능하면 NASA 공개 데이터(DONKI, OSDR, Artemis 등)를 쓰고, 게임 안에 출처를 표시할 것
  - 고정 데이터를 실시간처럼 보여 주지 말 것
  - 핵심 자원은 2~3개가 효과적, 너무 많은 시스템을 동시에 관리하게 하지 말 것
  - 반복 플레이 가치(판마다 다른 사건), 실패가 처벌처럼 느껴지지 않게
  - 어떤 NASA 데이터를 왜 썼는지 짧게 설명할 것
  - 다운로드나 계정 없이 브라우저에서 되는 형태가 유리

## PPT 3. 사용한 데이터

### 3.1 NASA DONKI (우주 기상)
- DONKI = Space Weather Database Of Notifications, Knowledge, Information. api.nasa.gov로 조회(팀 API 키 사용, 키는 저장소 밖에 보관).
- 쓰는 두 가지 현상(지원의 DONKI 제안서, Figma Page 1):

| 데이터 | 실제 현상 | 게임 속 사건 | 아이가 배우는 것 |
|---|---|---|---|
| SEP(태양 고에너지 입자) | 고에너지 태양 입자가 우주비행사의 방사선 피폭 위험을 높인다 | 15초 경보 뒤 1~2일 동안 야외 활동 금지, 로버 정지. 비축 자원으로 버텨야 한다 | 비상 상황에 대비한 자원 비축의 중요성 |
| GST(지자기 폭풍) | 지구 자기권 교란이 지구 쪽 통신과 지원 시스템에 영향을 줄 수 있다 | 1일 동안 지구 지원 링크 장애: 지도, GPS, 관제사 안내, 자율주행 로버 정지 | 우주 기상이 통신과 기술 시스템에 미치는 영향, 정보(통신)의 가치 |

- 교육 정확성 메모: 달에는 지구 같은 자기권이 없다. 그래서 GST 효과는 "달 표면 현상"이 아니라 "지구 쪽 지원 시스템(관제, 위치 정보)의 통신 장애"로 설명한다. 제안서 문구도 이렇게 되어 있다.
- 재생 방식: 실시간 반영은 하지 않는다(팀 결정). 과거 기록에서 사건이 적당히 있는 60일 구간 5개를 미리 골라, 게임 60일에 그대로 맞춰 재생한다. 판마다 구간이 무작위라 사건 순서가 달라진다(반복 플레이 가치). 화면에는 "NASA DONKI 관측 기록, 실제 날짜"를 함께 보여 준다(고정 데이터를 실시간처럼 보이지 않게).
- 공교롭게 DONKI API도 한 번에 60일까지만 조회된다(실측: 더 긴 범위는 "Date range cannot exceed 60 days" 오류). 게임 60일과 같다.

| SEP 발생 날짜 | 89일 |

| 연도별 SEP 날짜 | 2021년 7, 2022년 13, 2023년 18, 2024년 31, 2025년 20 |

- 태양 극대기 [확인 완료, docs/content/FACTS_V2.md 6.2]: 2024년 10월 15일 NASA와 NOAA가 "태양이 25번째 태양 주기의 극대기에 들어섰다"고 발표했다(https://www.spaceweather.gov/news/joint-solar-maximum-announcement-nasa-and-noaa). 우리 기록에서도 2023~2025년에 사건이 많았다. 단, SEP 날짜는 2024년이 최대이고 2025년에는 줄었다. "해마다 늘었다", "극대기는 2024~2025년"이라고 말하지 않는다.
- Kp 지수: 지자기 활동을 0~9로 나타내는 척도. NOAA 기준 Kp 5는 G1(약한 폭풍), Kp 6은 G2(중간), Kp 7은 G3(강함). 우리는 중간 이상(Kp 6+)만 사건으로 쓴다.

### 3.4 달 남극 착륙지 (Figma Flowchart, Page 1)
- 지도 출처 표기: NASA/GSFC/ASU/JSC/AGDT. 지도에 표시된 후보 지역 9곳: Peak near Cabeus B, Haworth, Malapert Massif, Mons Mouton Plateau, Mons Mouton, Nobile Rim 1, Nobile Rim 2, de Gerlache Rim 2, Slater Plain.
- [확인 완료, FACTS_V2.md 6.1] 이 9곳은 NASA가 2024년 10월 28일 발표한 달 남극 착륙 후보 지역 목록과 정확히 같다(https://www.nasa.gov/news-release/nasa-provides-update-on-artemis-iii-moon-landing-regions/). 원래 아르테미스 III용이었다.
- 주의(일정 변경, 2026-02-27 NASA 발표 직접 확인): 아르테미스 III는 2027년 지구 저궤도 시험 비행으로 바뀌었고, 첫 유인 착륙은 2028년 아르테미스 IV다(https://www.nasa.gov/news-release/nasa-adds-mission-to-artemis-lunar-program-updates-architecture/). 그래서 발표에서 "아르테미스 III 착륙지"라고 하지 않는다. 안전한 문장: "2024년 NASA가 발표한 달 남극 착륙 후보 지역 9곳(원래 아르테미스 III용)의 이름을 빌려 왔다."
- 우리 기지 배정(Figma "새로운 시나리오"). 기지 역할(통신, 발전, 식량, 탐사)은 우리 게임 설계이고 NASA가 지역별 역할을 정한 것이 아니다. 아래 근거 칸의 지역별 특징은 NASA 발표문에서 확인되지 않아 "우리 팀이 정리한 근거"로 표시한다. 지역별 수치를 말하려면 지원이 가진 원문(Artemis III Science Definition Team Report 등)을 출처로 붙여야 한다:

| 기지 | 착륙지 | 팀이 정리한 근거 |
|---|---|---|
| A 통신 | Malapert Massif | 지구 가시성이 거의 완벽, 중앙 통신 허브로 적합 |
| B 발전 | Mons Mouton Plateau | 연중 지속되는 낮과 짧고 불규칙한 밤 |
| C 식량 생산 | Nobile Rim 1 | 지표 아래 풍부한 물 얼음, 안정적인 태양광 |
| D 탐사 | Peak near Cabeus B | 지역 이름에 Cabeus가 들어간다. NASA LCROSS는 2009년 카베우스 크레이터에 충돌해 물을 찾았다(두 사실을 따로 말한다. "인근", "수소와 휘발성 화합물 확인"은 확인되지 않은 표현) |

- 달 남극을 고른 이유(Figma 스티커, 출처 https://www.nasa.gov/reference/moonbase-environment/): 지속적인 일조(태양이 지평선 가까이 낮게 뜸), 영구 음영 지역의 물 얼음 가능성, 남극-에이트켄 분지의 과학적 가치. 자전축 기울기가 작고 지형 높낮이가 커서 두 조건이 한곳에 공존한다.
- 얼음 후보지 배치: 지원이 실제 얼음 후보 좌표를 축소해 맵에 배치했다(지원 확인, 2026-11-14). 처음 기지 자리에서는 약 880~1,580 stud라 로버 왕복이 3~6일이나 걸려, 얼음 위치는 그대로 두고 기지를 얼음 쪽 평평한 자리로 옮겼다(지형 높이차를 측정해 선택). 이동 뒤 로버 출구에서 약 485~800 stud.
- 의사결정 포인트(발표용): "실제 좌표를 지키는 것"과 "놀 수 있는 시간"이 부딪혔을 때, 데이터(얼음 위치)는 바꾸지 않고 우리가 정할 수 있는 것(기지 위치)을 바꿨다.
- 지형: [확인 완료, 지원 답변과 Figma Page 1 "NASA LOLA DATA 지형데이터 활용" 프레임, 2026-11-14] 실제 NASA LOLA 고도 자료로 만들었다. 3.7절.

### 3.7 지형과 기지 선정 데이터 (지원의 분석, Figma Page 1 기록)
| 데이터 | 파일 | 내용 | 출처 |
|---|---|---|---|
| 지형 | NASA 고다드 PGDA `Site06_final_adj_5mpp_surf.tif` | LRO 탐사선 LOLA 레이저 고도계 관측 기반 고도 지도, 5 m/픽셀 | https://pgda.gsfc.nasa.gov/products/78 |
| 일조 | Wueller 등(2026) `Illumination_Modeling.zip` | 지상 2 m 높이에서 한여름 최장 연속 일조를 분석한 모델, 60 m/픽셀 | https://zenodo.org/records/17084058 |
| 영구 음영 | NASA LOLA 팀 `LPSR_85S_060M_201608.TIF` | 햇빛이 직접 들지 않는 영구 음영 지역 지도, 60 m/픽셀 | https://pgda.gsfc.nasa.gov/products/69 |

- 기지 위치 선정 순서: 완만한 지형 선별 -> 일조 조건 비교(2026~2032년 한여름) -> 영구 음영 지역 접근성 검토.
- 선정 부지: Nobile Rim 1의 2번 후보. 기지 후보 중심 남위 85.04134도, 동경 37.50358도. 핵심 부지 640 x 640 m, 경사 중앙값 약 3.02도, 핵심 부지 고도차 약 32.6 m, 가장 가까운 영구 음영 지역까지 중심 기준 약 310 m.
- 높이맵 구현: NASA 고도 지도에서 2.56 x 2.56 km 구역 추출 -> 16비트 PNG 높이맵(512 x 512 픽셀, 원본 5 m/픽셀 유지, 고도 6,410.84~6,684.30 m) -> Roblox Terrain. 게임 맵 약 2,044 stud이므로 1 stud는 약 1.25 m.
- 얼음 배치: 지형 높이 25곳을 원본과 대조해 방향과 축척을 확인한 뒤, 게임 좌표를 실제 달 좌표로 바꿔 ICE 1~5를 영구 음영 지역에 맞춰 배치했다. ICE는 "얼음이 확인된 지점"이 아니라 "얼음 탐사 후보지"다(게임 안 표현도 이렇게 맞춘다).
- 아르테미스 표현: 지원 확인, "2024년 발표한 후보 지역"으로 말한다.
- 발표용 한 문장(지원 정리, 2026-11-14): "Nobile Rim 1은 아주 넓은 구역이라, 그 안에서 일조량과 얼음 후보 지역의 균형이 좋은 곳을 실제 NASA 데이터로 고르고, 게임 환경에 맞게 크기만 조절했다."
- 발표 포인트: 지형, 일조, 영구 음영 세 가지 실제 NASA 데이터로 기지 자리와 얼음 후보지를 골랐다. 그래서 게임 속 "가까운 얼음 vs 먼 얼음" 선택이 실제 지형 조건에서 나온다.

- GST 표현 주의: NASA 문장 중에 "지자기 폭풍이 달과 지구 사이 통신을 끊는다"는 것은 없다. NOAA가 드는 영향은 GPS 오차, 단파(HF) 무선, 전력망이다. 게임 문구는 "지구 쪽 지원 시스템(위치 정보, 관제) 장애"로 쓴다.

### 3.6 게임 안 출처 표시 (grill Q36)
- 사건이 뜰 때: 실제 날짜 + "NASA DONKI"
- 결과 화면: "이번 판의 우주 날씨: 실제 기록 구간, SEP n회, GST n회"

## PPT 4. 해결방안 (How it works)

### 4.1 한 판의 흐름 (C 식량 생산 기지 기준)
1. 미션 선택: 달 남극 지도에 네 기지. C 플레이 가능, B 곧 열림, A와 D는 준비 중(눌러서 역할과 NASA 근거는 읽을 수 있음).
2. 착륙 -> 에어록 점검(2일, 산소 회복 시설 가동) -> 태양광 패널 설치(하루 2장, 최대 20장).
3. 물 확보: 얼음 후보지 5곳. 혼자면 로버를 자율주행으로 보내고, 여럿이면 직접 운전한다. 한 지점은 캐고 나면 3일 쉬어야 해서 여러 곳을 돌아야 한다.
4. 식량 재배 공간 건설(5일마다 자동 수확) -> 업그레이드 3종.
5. 로버 물 하역 5회 뒤 파이프 해금(얼음 지점 하나 자동화).
6. 금메달 조건을 채우면 바로 임무 완료, 못 채우면 60일째 지은 만큼 메달.

### 4.1.1 시뮬레이션으로 난이도 설계 (발표 소재)
- 전체 과정과 숫자: `docs/BALANCE_LOG.md`. 회의 숫자 그대로면 처음 하는 아이도 금메달 100%였던 데서 출발해, 봇 3종 x 실제 NASA 우주 기상 구간 5개로 수백 판을 돌려 조정한 기록. 8절에 발표용 메시지 7개.

### 4.2 핵심 숫자 (출발값, 봇 시뮬레이션으로 조정 중)
| 항목 | 값 |
|---|---|
| 하루 / 전체 | 30초 / 60일(30분 이내) |
| 시작 자원 | 에너지, 물, 식량 각 70, 상한 100 |
| 하루 기본 소비 | 식량 3, 물 3, 에너지 12 |
| 실패 | 물이나 식량이 0인 날이 4일 연속 |
| 산소 | 야외 60초에 100 소모. 0이면 실패가 아니라 에어록으로 구조되고 점수 감점 |

### 4.3 모든 선택에 대가가 있다 (트레이드오프 목록)
| 선택 | 얻는 것 | 잃는 것 |
|---|---|---|
| 가까운 얼음 vs 먼 얼음 | 가까우면 싸고 빠름 | 가까운 곳은 쿨타임 3일. 먼 곳은 에너지와 파손 위험이 큼 |
| "서둘러 가기" | 이동 시간 단축 | 파손 위험 한 단계 상승 |
| 파이프(럭셔리) | 로버 없이 3일마다 물 30 | 에너지 15, 건설 5일, 매일 유지비. 그 지점은 로버로 못 캠 |
| LED 조명 | 수확 주기 5일 -> 4일 | 전력 소비 증가 |
| 영양분 관리 | 재배 공간의 물 사용 절반 | 건설비와 유지비 |
| 시설 잠깐 멈추기 | 물과 전력 절약 | 그동안 생산과 효과 정지 |
| 로버 고장 | 걸어가 수리하면 물을 지킴 | 산소와 거리 위험. 원격 회수는 안전하지만 하루와 물을 잃음 |
| 우주 기상 대비 | 미리 비축하면 안전 | 비축하느라 건설이 늦어짐 |

### 4.4 협동과 역할 (여럿이 할 때)
- 관제사 1명: 전체 지도를 보고 목표 핀을 찍는다. 탐사대원 화면에 방향 화살표가 뜬다. NASA 관제(Mission Control)와 우주비행사의 관계를 그대로 옮겼다.
- 탐사대원 1~2명(로버 운전, 얼음 채취), 엔지니어 0~1명(패널, 건설).
- 채팅 없이도 협동이 된다. [확인 완료, FACTS_V2.md 6.3] Roblox는 2026년 1월부터 전 세계에서 채팅에 나이 확인을 요구하고, 만 9세 미만은 부모 동의가 있어야 체험 안 채팅이 켜지며, 만 13세 미만끼리의 채팅은 엄격히 필터링되고, 9~12세는 음성 채팅을 쓸 수 없다(https://about.roblox.com/safety, https://about.roblox.com/newsroom/2026/01/roblox-age-checks-required-to-chat). 그래서 말 대신 핀 화살표로 안내한다. "13세 미만은 채팅할 수 없다"는 틀린 표현이라 쓰지 않는다. 정책이 자주 바뀌니 발표 직전에 다시 확인.
- 지자기 폭풍(GST)이 오면 지도와 화살표가 끊긴다. "통신이 끊기면 협동이 깨진다"를 몸으로 배운다.
- 목업: https://claude.ai/artifact/D6knXD7jorqgZ2TmyALxAy

### 4.5 점수, 메달, 순위
- 메달(C): 동 = 식량 재배 공간, 은 = + LED + 영양분 관리, 금 = + 수경 재배(파이프 필요).
- 숨은 점수: 1000점에서 시작해 자원이 20 아래(-10), 0(-30), 산소 구조(-100)마다 감점. 플레이 중에는 숨기고 결과 화면에서 이유와 함께 보여 준다. "아이콘이 뜨면 점수가 깎인다"로 비축을 배우게 한다.
- 순위: 미션별 순위와 전체 리더보드(금메달을 딴 미션 수).

### 4.6 7~12세를 위한 설계
- 숫자 대신 아이콘. 물이나 식량이 부족하면 대원 머리 위에 상태 아이콘.
- 기분 나쁘지 않은 실패 화면과 "다음엔 이렇게 해 보자" 한 줄.
- 로버 이동 시간에 사실 카드.
- 영어 기본, 한국어 전환(같은 서버에서도 아이마다 다른 언어 가능).
